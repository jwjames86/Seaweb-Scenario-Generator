How to Use Real Sailing SearchFind a public NCL sailing to use in a new-reservation scenario
  • Choose a From date. The To date automatically fills 30 days later; shorten it if needed.
  • Use only one main search filter: Destination, Embarkation Port, or Ship. Vacation Length is optional.
  • After the search results load, use the Choose Itinerary & Specific Sailing Date section underneath the results. Pick the itinerary from the first dropdown, then pick the exact sailing date from the second dropdown. If NCL does not expose exact dates, a verified date field appears instead.
  • Use port-of-call requirements after retrieving results instead of over-filtering the initial search.
  • This tab uses the U.S. NCL site at ncl.com. Verify cabin inventory, exact pricing, and internal rules in Seaweb.

Scenario Generator

Create a structured Seaweb exercise with a guided step-by-step setup, clearer scenario focus selection, and a cleaner trainer workflow.

How to Use Scenario GeneratorCreate, review, clear, share and save an exercise
  • Choose the Department, Reservation Workflow, one or more Scenario Focus skills, difficulty, and scenario approach.
  • For Create New Reservation, choose the Caller Type first. Direct Guest — US automatically uses Agency 5, Direct Guest — Canada uses Agency 7, and Travel Agent requires the Travel Agent’s Agency ID or phone number. Scenario wording follows the selected caller type.
  • For Modify Existing Reservation, enter the prior training reservation number and choose exactly what is being changed. Guest Services modifications require GDPR setup.
  • For Air scenarios, select Include Air / Transfers, choose the Air product, and choose Round Trip or One Way. The applicable training terms and transfer reminder will appear automatically.
  • When applying FCC, CruiseNext, CruiseFirst, discount coupons, or other training credits, use Credits & Coupons to identify each item and the Latitudes profile it comes from.
  • When a payment is required, choose a training-card profile and edit the card information if the exercise needs different training data.
  • Select Generate Scenario, then review the card on the right. Trainer View includes coaching information; Trainee View hides trainer-only content.
  • After a scenario is created, select Make Roleplay to instantly convert it into a two-person Cruise Specialist / Caller roleplay. Select Standard Scenario to change it back.
  • Select Create Follow-Up Roleplay to turn the completed reservation into a new servicing call. Choose the changes the caller wants to make, add your own custom instructions, and the generator creates a separate GDPR-based servicing roleplay.
  • Use Start New Scenario to clear the current setup and generated scenario before building a completely different exercise.

V1 saves locally to this browser. Export a backup before switching devices.

How to Use Saved Scenario LibraryReuse, duplicate, organize and back up scenarios
  • Use the department filter or search box to find a saved scenario.
  • Open loads the scenario back into Scenario Generator so you can edit or regenerate it.
  • Duplicate creates a separate copy you can modify without changing the original.
  • Use Favorites and Archive to organize frequently used and retired scenarios.
  • Export JSON creates a backup of the browser-local library. Use Import JSON to restore or move scenarios to another browser.
